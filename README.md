***KNIGHTFALL***-пиксельная 2D инди игра в жанре DARKFANTASY с линейным сюжетом и механиками ближнего и дальнего боя с использованием магии 4 стихий.

**Целью проекта** является создание игры с вышеперечисленными особенностями, а также получить опыт в разработке и научиться работать в команде. Для этого необходимо выполнить следующие **задачи**:

• Написание саундтреков

• Разработка основных механик

• Отрисовка спрайтов

• Дизайн уровней, подходящих под выбранный сетинг

• Работа в команде посредством распределения ролей и постановке различных задач
